### Overview of the Responsibilities

- Design and build agentic workflows where agents can reason, use tools, call APIs, interact with other systems, handle retries and failures, wait for human approval, and safely continue long-running processes.
- Build business automation workflows such as: Collect data –> Analyze –> Prepare report –> Send email –> Get approval –> Continue process –> Update systems.
- Build integrations using Model Context Protocol (MCP), including MCP servers, clients, tools and enterprise APIs.
- Work with MCP Apps, Generative UI and A2UI where they can improve the user experience.
- Design context, memory and workflow state. Use RAG and enterprise knowledge retrieval where needed.
- Design AI systems for better performance and lower cost using model routing, context optimization, caching, semantic caching, batching and other suitable techniques.
- Design LLM-agnostic architectures and model-routing strategies. Select the right model based on task complexity, capability, cost, latency, context size and privacy requirements. Decide when to use smaller or local models and when to use frontier models.
- Decide where AI actually adds value and where normal deterministic software is the better solution.
- Implement AI observability and evaluation, including tracing, latency, cost monitoring, failure handling and regression testing.
- Make agentic workflows production-reliable using retries, backoff, idempotency, timeouts, circuit breakers, fallbacks and safe rollbacks for long-running processes.
- Establish AI governance, security and guardrails, including data privacy, model and tool access, human-in-the-loop controls and auditability.
- Help design Agentic SDLC workflows around requirement analysis, planning, development, testing, code review and documentation.

### Key Requirements

- Hands-on experience with one or more **agentic platforms or AI frameworks**.
- Hands-on experience designing and building production applications using LLMs, Generative AI or Agentic AI.
- Strong understanding of LLM orchestration, model routing, agentic architecture, tool/function calling, MCP, workflow orchestration, RAG, context and memory management.
- Good understanding of AI security, governance, evaluation, observability, performance and cost optimization.
- Ability to evaluate new AI technologies and decide when and how they should be used in a real software product.
- Strong programming experience in at least one language such as Python or C#.
- Ability to use cutting edge technologies like AI to efficiently deliver tasks.
